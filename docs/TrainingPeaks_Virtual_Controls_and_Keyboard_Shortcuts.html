    TrainingPeaks Virtual Controls and Keyboard Shortcuts

    TrainingPeaks Virtual fully supports a wide variety of controls for the most common in-game actions, such as operating menus, camera control, changing Virtual Gears, Tactical Positioning, and Braking.

    This article documents the specific controls available for:

    • Mouse / Touch Screen
    • Keyboard Shortcuts
    • Smart Bike Buttons (such as those built into the Wahoo Kickr Bike)
    • AppleTV Siri Remote
    • 3rd Party Game Controllers (such as Avotro cycling controllers, or Xbox / PlayStation game controllers)

    Mouse / Touch Screen Control

    Mouse-driven menus are available throughout. When riding in game by default, these are hidden from view; move the mouse to (or touch on a touch screen):

    • The bottom left corner of the screen to access the in-game menu
    • The bottom middle of the screen to show the most commonly used quick select action buttons.

    Smart Bike Mapping

    TrainingPeaks Virtual supports the use of built-in buttons on a range of Smart Bikes. If your Smart Bike is not listed here and you would like to see it supported, please contact TrainingPeaks Virtual at virtual@trainingpeaks.com

    • Wahoo Kickr Bike
      • Left/Right Function: Junction Direction Selection / Tactical Positioning
      • Left/Right Brake: Brake
      • Right Plus: Rotate Camera View
      • Right Minus: Hold to U-Turn (Free Riding) / Tap or Hold to Glance Backwards (Events)
    • Tacx Neo Bike
      • Left/Right: Junction Direction Selection / Tactical Positioning
    • Stages SB20 Bike
      • Left/Right: Junction Direction Selection / Tactical Positioning
    • Muov Bike
      • Left/Right: Junction Direction Selection / Tactical Positioning

    AppleTV Siri Remote

    TrainingPeaks Virtual uses the following mapping of controls on the Apple TV Siri Remote:

    • Touch Pad Click Centre: Select
    • Touch Pad Click Top/Bottom/Left/Right: Navigate Menus
    • Touch Pad Swipe: Navigate Menus
    • Menu: Menu / Cancel (also, hold down to exit application)

    Game Controller Mapping

    For ease of use, TrainingPeaks Virtual uses the same controller layout for all Game Controllers – Avotro, Xbox, PlayStation, etc.

     

    • A: Select
    • B: Cancel
    • Menu: Menu
    • D-Pad Up: Navigate Menus / Quick Action Menu
    • D-Pad Down: Navigate Menus / Hold to U-Turn (Free Riding) / Tap or Hold to Glance Backwards (Events)
    • D-Pad Left: Navigate Menus / Junction Select / Tactical Positioning
    • D-Pad Right: Navigate Menus / Junction Select / Tactical Positioning
    • Joystick Left: Drone Camera Control Zoom In/Out & Change Viewed Rider
    • Joystick Right: Drone Camera Control Up/Down/Left/Right
    • Joystick Left Button: Camera to Self
    • Joystick Right Button: Camera to Leader (Events)
    • Shoulder Button 1 (Left/Right): Tab Menus / Virtual Gear Selection / Workout Difficulty Adjust
    • Shoulder Button 2 (Left/Right): Tab Menus / Junction Direction Selection / Tactical Positioning

    Note that additional 3rd party drivers may need to be installed for Xbox and PlayStation controllers for compatibility with your computer – please see the controller manufacturer's instructions for details. Avotro cycling controllers work directly in TrainingPeaks Virtual via plug-and-play, with no additional configuration or pairing required. Zwift controllers are not compatible devices as they are proprietary to Zwift.
